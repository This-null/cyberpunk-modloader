# CP2077 Mod Launcher

[English](README.md) | [Türkçe](README.tr.md) | [Русский](README.ru.md) | [Español](README.es.md) | [Português (BR)](README.pt-BR.md) | [Français](README.fr.md) | [Polski](README.pl.md) | [Deutsch](README.de.md)

Неофициальный менеджер модов для Cyberpunk 2077 на Windows, сделанный сообществом. Версия 0.0.1 beta.

Он не создан CD PROJEKT RED, Nexus Mods или командой NightCoop и не связан с ними.

## Что он умеет

- Устанавливает моды из файлов .zip, .rar и .7z. Перетащите файл в окно или нажмите «Установить мод».
- Включает мод, копируя его файлы в папку игры, и выключает, удаляя ровно эти файлы. Перезаписанные файлы сохраняются и возвращаются обратно.
- Предупреждает, если мод перезапишет файл другого мода.
- Находит моды, которые вы поставили вручную, и позволяет их импортировать.
- Собирает несколько версий одного мода в одну карточку, видно, какая из них актуальная.
- Проверяет и устанавливает сборки NightCoop с официального сайта, каждую загрузку проверяет по SHA-256.
- Просматривает Nexus Mods с поиском, фильтрами, тегами и бесконечной прокруткой. Бесплатные аккаунты могут ставить моды через ссылки nxm или из папки загрузок.
- Показывает логи игры, модов и лаунчера и очищает их по вашей просьбе.
- Работает на английском, турецком, русском, испанском, бразильском португальском, французском, польском и немецком.
- Есть системная, тёмная и светлая темы.

## Установка

1. Скачайте zip-файл на странице [Releases](https://github.com/This-null/cyberpunk-modloader/releases).
2. Распакуйте его и запустите установщик.
3. Windows может показать предупреждение SmartScreen, потому что установщик не подписан. Выберите «Подробнее», затем «Выполнить в любом случае».

## Конфиденциальность

Ничего не отправляется автоматически. Отчёты об ошибках сохраняются только на вашем компьютере. Лаунчер обращается к сайту NightCoop и Nexus Mods, чтобы показывать и скачивать моды. Заметки к выпуску уходят в Google Translate только если вы разрешите это в настройках. Ваш ключ Nexus API хранится в диспетчере учётных данных Windows на вашем компьютере.

## Сборка из исходников

Нужны Node 20 или новее, pnpm и стабильный Rust.

```
pnpm install
pnpm tauri dev
pnpm tauri build
```
